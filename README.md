# Currency Converter 

A responsive web application that allows users to convert between different currencies using **real-time exchange rates fetched through an API**.

## Features

* Real-time currency exchange rates
* Supports multiple currencies
* Instant currency conversion
* Simple and user-friendly interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* Exchange Rate API

## How It Works

1. Select the currency you want to convert from.
2. Select the target currency.
3. Enter the amount.
4. The application fetches the latest exchange rate through the API and displays the converted amount.
